인터넷 없이 사용

추가 결제 없음

처음에는 인터넷으로 앱과 무료 모델 파일을 준비해야 합니다.

아이폰에서 시작하기
  1. HTTPS 주소를 Safari로 열고 공유 → 홈 화면에 추가를 누르세요.
  2. 홈 화면의 PREX에서 오프라인 사용 준비를 완료하세요.
  3. 카메라를 허용하고 참가자·손·병 조건을 입력하세요.
  4. 기준 잡기 → 7초 관찰 순서로 진행하세요.

영상은 서버에 보내지 않습니다. 앱 데이터 삭제에 대비해 JSON과 CSV를 내보내 두세요. 브라우저가 저장 공간을 비우면 모델을 다시 준비해야 할 수 있습니다.

설치 주소와 지원 환경

Safari에서 홈 화면에 추가하는 웹앱입니다. 무료 GitHub Pages 등 HTTPS 정적 호스팅을 사용합니다. 설치 후에는 PC 분석 서버 없이 아이폰 자체에서 처리합니다.

iOS 17 이상 Safari를 대상으로 합니다. 파일 앱에서 HTML을 열거나 휴대폰으로 일반 HTTP 주소에 접속하면 카메라를 사용할 수 없습니다. 실제 아이폰의 인식률·속도·발열은 별도 확인이 필요합니다.

무엇을 측정하나요?

손 기준점 21개에서 관절 각도 14개를 계산합니다. 엄지 MCP·IP 2개와 나머지 네 손가락 MCP·PIP·DIP 각 3개입니다. 네 손가락 MCP는 손목을 손바닥 쪽 기준으로 사용한 기하학적 각도입니다.

병 모델은 후보 위치를 찾습니다. 보이는 양옆 경계를 비교하고 손에 가린 구간의 추정값을 직접 관측과 분리합니다. 병 추적 실패가 손 관절 값까지 지우지 않습니다.

P90은 90백분위수입니다. 속도·가속도는 연결된 유효 프레임에서 계산하며 누락 구간을 이어 계산하지 않습니다.
