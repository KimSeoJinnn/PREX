# PREX 페트병 쥐기 영상 분석

한 손의 랜드마크 21개와 관절 각도 14개를 추적하고 마커 없는 병의 변형을 기록하는 Windows 실험용 프로그램입니다. **기본 측정은 뚜껑 중심–바닥 중심의 기준축과 31개 단면 윤곽 비교**입니다. 관절·윤곽 feature 추출, 개인 보정 기반 kgf 환산, 참가자를 분리한 모델 학습·비교를 지원합니다. 실제 악력 정확도와 임상적 유효성은 검증되지 않았습니다.

영상 분석은 로컬 PC에서 실행합니다. 별도 결제가 필요한 API·서비스·클라우드 연산은 사용하지 않습니다. 사용자 비용 지침은 AGENTS.md에도 기록했습니다.

## 설치

Windows의 64비트 Python 3.12와 웹캠을 사용합니다. 프로젝트 폴더에서 실행합니다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Git Bash에서는 `./.venv/Scripts/python.exe main.py` 형식을 사용합니다. 학습 모델 파일은 저장소에 포함하지 않으며, 첫 실행 시 필요한 무료 모델을 다운로드합니다. 이후 영상 분석은 로컬에서 수행합니다. 가상환경, 촬영 기록, 개인 보정값, 분석 결과, 디버그 영상, 회사 공유용 문서는 업로드 대상에서 제외합니다.

## 자동으로 시험하기 — 두 점 선택 불필요

```powershell
.\.venv\Scripts\python.exe main.py
```

병을 누르지 말고 뚜껑과 바닥이 모두 보이도록 보여주세요. 병을 찾은 뒤 몸통을 가볍게 잡고 **H**를 눌러 이완 기준을 설정합니다. 기준 설정이 끝나면 **G**를 누르고 **2초 이완 → 3초 최대 쥐기 → 2초 이완** 안내에 따릅니다. 촬영은 자동 종료됩니다. 다음 촬영도 H → G로 진행합니다. **R**은 별도의 수동 원시값 기록입니다. 두 점을 클릭할 필요가 없습니다. **A**는 병 탐색과 기준값을 처음부터 다시 시작합니다.

`grip_settings.json`의 `self_temp`에만 임시 정답 **80kgf**를 적용합니다. 실제 악력계 측정값이 아니며, 첫 유효 촬영은 개인 보정 기준으로 저장됩니다. 이후 촬영에서 기준 대비 변화량으로 실험용 환산값을 계산합니다. 재실행해도 보정값은 유지되며, H는 영상 기준선만 다시 설정합니다. 정답 하나에 맞춘 환산은 정확도 검증이 아닙니다. 다른 사람은 반드시 다른 `--participant`로 실행하세요.

촬영 결과는 `recordings/`에 저장합니다. `*.csv`는 프레임별 원시값, `*.features.csv`와 `*.features.json`은 실험 요약 feature, `*.estimate.json`은 보정 또는 예측 결과입니다. 처음 보정한 기록에서는 예측값 `kgf`가 비어 있습니다. 분홍선은 손에서 계산한 추정 윤곽이며 실제 병 테두리 측정값과 구분합니다.

처음 기준값을 잡을 때는 **뚜껑과 바닥을 가리지 않으면서 병목을 가볍게 잡아 몸통 양옆을 보여주세요.** 기준값이 준비된 뒤 몸통을 쥡니다. 손이 양옆을 모두 가리면 병 위치와 관절은 추적해도 몸통 폭을 측정하지 않습니다. `Bottle tracked; show both body sides`는 병 축을 추적하고 있지만 폭 계산에 필요한 양쪽 경계가 부족하다는 뜻입니다.

오른쪽 위 **Bottle: tracked / recovering / searching**에서 병 축의 추적 상태를 확인합니다. 아래 **Edges L / R**는 각각 보이는 몸통 좌우 경계 수이고, **Width**는 같은 높이에서 양쪽 모두 관찰한 단면 수입니다. 한쪽 윤곽만 보여도 화면에 표시하지만, 한쪽 윤곽으로 폭이나 악력을 계산하지 않습니다.

**파란색은 관찰한 병의 테두리, 초록색은 손 관절**입니다. 파란 점은 한쪽 경계만 관찰돼도 표시합니다. 31개 측정 높이 사이에 짧게 보이는 테두리도 파란 선으로 표시하지만, 이 추가 표시는 폭·변형 계산에 넣지 않습니다. 손에 가려 선이 끊기는 것과 병 자체를 찾지 못하는 것을 구분하세요. `Bottle: tracked`이면 뚜껑–바닥 위치는 추적 중입니다.

기본 인식 경로는 **YOLOX-416의 전체 병 검출 → 현재 영상에서 뚜껑·바닥 테두리 확인 → 광학 흐름 추적과 끝점 재관찰 → 실제 몸통 경계 비교**입니다. 저장된 실제 촬영 장면에서는 YOLO11n-seg가 병 윗부분만 검출하는 경우가 있어 기본 검출기를 바꿨습니다. 같은 병의 윗부분과 전체 상자가 중복되면 전체를 남기고, 분석하기에 너무 작은 배경 병은 선택 후보에서 제외합니다. 서로 다른 큰 병이 여러 개면 손과 가까운 병을 구분할 수 있을 때만 선택합니다.

기본 화면의 모델 이름은 **Model: yolox_416_detection_only**입니다. 기존 models/object_detection_yolox_2022nov.onnx를 재사용하며, 없으면 백그라운드에서 받습니다. 이 모델은 병 상자를 찾으며 분할 마스크는 제공하지 않습니다. 뚜껑 후보를 고를 때 색이 진한 배경 띠를 제외하고, 병 윗부분만 잡혔으면 그것을 전체 병으로 확정하지 않고 주변을 다시 검사합니다. 뚜껑/바닥 전용 키포인트 모델은 아니므로 CAP/BASE가 실제 위치와 맞는지 확인하세요.

분할 모델을 비교하려면 `--bottle-backend segmentation`으로 실행합니다. 호환되는 로컬 ONNX는 `--segment-model 경로`로 지정합니다. 기본 검출기 로딩에 실패하면 분할 모델도 시도합니다. 실제 선택 모델은 터미널과 오른쪽 아래에 표시합니다.

병을 찾는 것과 찌그러짐을 측정하는 것은 별개입니다. 병을 검출해도 손에 가리거나 투명 경계가 약하면 `Bottle located; contour weak or occluded`로 표시하고 변형값을 비웁니다. **분할 마스크나 검출 상자의 폭 변화를 찌그러짐으로 기록하지 않습니다.** 기본 경로에서 느린 전체 화면 뚜껑 후보·허프 선분 탐색은 사용하지 않습니다.

| 기본 자동 모드 키 | 기능 |
| --- | --- |
| A | 병 자동 탐색 및 기준값 초기화 |
| B | 3초 준비 후 기준값 재수집 |
| H | 현재 손·병 자세의 이완 기준 및 분홍색 추정선 기준 재설정 |
| G | 이완·최대 쥐기·이완 안내 촬영 및 feature·결과 자동 저장 |
| R | 기준값 준비 후 CSV 기록 시작/종료 |
| D | 원본 카메라 영상, 미리보기, 분석 원본과 상태 JSON을 debug/scene_날짜_시간*로 저장 |
| Q / Esc | 기록 저장 후 종료 |

기록 중에는 A/B로 측정 기준을 바꿀 수 없습니다. 문제가 나타나는 순간 **D**를 누르면 .png(현재 카메라), _preview.png(표시 화면), _analysis.png(분석한 프레임, 분석 결과가 있을 때), .json(프레임 번호·모델·축/손 검출·기준값·좌우 경계 수·지연)을 함께 저장합니다. 현재 영상과 분석 영상의 시점이 달라도 JSON에서 구분할 수 있습니다. D를 누를 때만 이미지가 저장됩니다.

## 화면 끊김과 분석 속도

카메라 읽기, 손·윤곽 분석, 병 모델 추론, 화면 표시를 분리했습니다. **병 모델을 불러오거나 추론하는 동안에도 손 분석을 계속합니다.** 각 분석 대기열에는 최신 프레임 하나만 유지하므로 오래된 영상이 쌓이지 않습니다. 병 모델의 이전 프레임 좌표는 현재 영상에서 뚜껑·바닥을 다시 관찰하거나 광학 흐름을 확인한 뒤 사용합니다. 분석하지 않는 대기 주기가 정상 검출 결과를 덮어쓰지 않도록 했습니다. 미리보기의 선 합성은 OpenCV 마스크 복사로 처리해 매 화면의 큰 NumPy 배열 연산을 줄였습니다. 오래된 선을 숨기는 250ms 기준은 유지합니다.

손·윤곽 분석은 기본 최대 12fps이며, OpenCV 작업 스레드는 기본 2개로 제한합니다. 전체 화면에서 손을 놓치면 병 주변의 정사각형 영역을 확대해 재검사합니다. 두 화면 크기의 손 추적 상태는 따로 유지하며, 확대 영상의 좌표는 원래 카메라 좌표로 되돌립니다. 손을 검출하지 못한 프레임에 과거 관절 각도를 복사해 기록하지 않습니다.

화면의 `Preview / Analysis / Age`는 미리보기 속도, 손·윤곽 분석 소요 시간, 결과 프레임의 촬영 후 경과 시간입니다. 250ms보다 오래된 윤곽은 현재 카메라 화면에 겹쳐 표시하지 않고, 오른쪽 측정값은 분석 시점의 값으로 유지합니다. 500ms가 넘으면 오래된 분석임을 추가로 표시합니다.

CPU가 느린 경우 분석 상한만 낮출 수 있습니다. 실제 속도는 카메라와 컴퓨터 성능에 따라 달라집니다.

```powershell
.\.venv\Scripts\python.exe main.py --analysis-fps 8 --opencv-threads 2
```

카메라 CSV에는 **실제로 분석한 프레임만** 한 번씩 기록하고 시간은 촬영 시각을 사용합니다. 분석하지 않은 프레임의 값을 보간하거나 복제하지 않습니다. 저장된 동영상의 오프라인 분석은 모든 프레임을 순서대로 처리합니다.

추적을 놓치면 현재 뚜껑의 색·모양과 바닥 테두리를 작은 영역에서 재관찰하고, 확인되지 않으면 병 모델로 다시 찾습니다. 기준값 수집 전에는 약 0.8초 이상 축을 놓치면 오래된 위치 제한을 해제하고 현재 화면에서 새로 탐색합니다. 기준값이 있는 상태는 그대로 유지하며 복구합니다. 직접 재관찰한 두 끝점은 뚜껑 색, 바닥 바로 위의 병 무늬, 끝점 가림, 이동·크기를 확인합니다. 일반 상자/광학 흐름 후보는 기존 외관 검사를 유지합니다. 확인하지 못한 프레임의 측정값은 비웁니다. 실제 투명 PET병 동영상에서 검증한 인식률은 아직 없습니다.

### 병목에서 몸통으로 손을 옮길 때

기준 폭에 숫자가 나온 뒤 손을 몸통으로 옮깁니다. 뚜껑과 바닥이 보이면 몸통이 가려져도 기준축 복구를 시도합니다. 손 위치가 달라졌다는 이유로 초기 영상의 주변 모습과 계속 비교하다 막히지 않도록, 직접 두 끝점을 확인한 복구에서는 **추적용 영상만 갱신하고 변형 측정용 기준 윤곽은 유지**합니다. 복구할 때 A/B를 누를 필요는 없습니다. 초기 잘못된 윤곽을 폐기하는 별도 규칙은 유지합니다.

기존에는 AI 재검출 결과도 실패한 광학 흐름 검증을 다시 통과해야 해서 `Bottle detected; hold still briefly for alignment`에서 빠져나오지 못할 수 있었습니다. 현재는 최신 화면에서 양쪽 끝점과 바닥 무늬를 확인하는 경로가 있습니다. 몸통 경계가 손에 가려지면 폭·찌그러짐 값은 계속 비워둡니다. `Bottle: tracked`와 `Width 0/31`이 함께 나타날 수 있습니다.

## 선택 기능: 수동 두 점 방식

프로젝트 폴더의 PowerShell에서 실행합니다.

```powershell
.\.venv\Scripts\python.exe main.py --manual-bottle
```

1. 병을 누르지 않은 상태로 뚜껑과 바닥이 화면 안에 보이게 둡니다.
2. **P**를 누릅니다. 멈춘 화면에서 **뚜껑 가운데 → 바닥 가운데** 순서로 두 번 클릭하고 Enter를 누릅니다. 오른쪽 클릭/Backspace로 되돌리고 Esc로 취소합니다. 두 점은 분석 영상에서 80px 이상 떨어져 있어야 합니다.
3. 노란 축과 CAP/BASE가 병을 따라가는지 확인합니다. 파란 윤곽도 실제 병 바깥 경계인지 확인하세요. 처음에는 손이 몸통 양옆을 가리지 않게 해 기준 윤곽을 확보합니다.
4. **B**를 누르면 3초 뒤 1초 동안 기준값을 모읍니다. 병을 누르지 말고 유지하고 `Baseline ... Bottle OK`를 확인합니다. 손 각도 기준값도 필요하면 병을 가볍게 잡되 경계가 보이게 합니다.
5. **R**로 기록을 시작하고 쥐었다가 풀기를 반복합니다. R로 기록을 끝내고 Q 또는 Esc로 종료합니다.

처음 두 점을 지정한 뒤에는 주변 특징점과 영상 패치로 추적합니다. 스티커는 필요하지 않습니다. 기록 중에는 기준값/영역을 변경할 수 없습니다.

| 키 | 기능 |
| --- | --- |
| P | 뚜껑/바닥 중심 지정, 기준값 초기화 |
| A | 병 검출 모델로 자동 후보를 다시 찾음, 기준값 초기화 |
| B | 3초 준비 후 1초 기준값 수집 |
| R | CSV 기록 시작/종료 |
| E | 이전 몸통 사각형/가로 띠 방식으로 전환 |
| Q / Esc | 종료 |

새 환경은 64비트 Python 3.12로 설치합니다. 기존 .venv가 있으면 재설치할 필요가 없습니다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 자동 후보와 수동 두 점

```powershell
.\.venv\Scripts\python.exe main.py
```

기본 실행은 위의 자동 탐색·자동 기준값 수집 방식입니다. 자동 모드에서는 두 점 선택 창이 열리지 않습니다. 아래의 P/B 조작은 수동 모드의 선택 기능입니다.

`--manual-bottle`은 자동 후보 단계를 건너뜁니다. 손 추적 모델만 있으면 두 점 방식 전체를 사용할 수 있습니다. 새 의존성은 추가하지 않았습니다.

## 측정 방식

- 뚜껑/바닥 주변 특징점의 광학 흐름을 추적합니다. 왕복 오차, 두 영역의 지지점, 최초 영상 패치와의 일치도를 검사합니다. 보조 템플릿 검색도 사용하지만 대응이 모호하면 측정을 중단합니다.
- 두 점으로 병을 세우고 축 길이를 320으로 맞춘 영상으로 정렬합니다. 화면 안의 이동·평면 회전·균일 확대/축소를 보정합니다.
- 뚜껑→바닥 길이의 27~87%에서 고정된 31개 단면을 비교합니다. 경계의 밝기 방향과 이웃 높이의 윤곽 연속성을 함께 사용해 내부 반사선으로 옮겨가는 현상을 줄입니다.
- 기준 구간에서 단면별 좌우 경계의 중앙값과 폭의 MAD 기반 흔들림을 구합니다. 같은 높이의 현재 윤곽과 비교해 폭, 국소 함몰, 비대칭, 가시 면적 변화를 계산합니다.

노란색은 축, 회색은 기준 윤곽, 파란 선과 점은 관찰한 병 윤곽, 초록색은 손 관절입니다. 몸통 좌우 윤곽은 독립적으로 표시하고, 목·바닥 주변과 측정 높이 사이의 관찰 가능한 윤곽도 표시합니다. 추가 표시를 폭·면적·변형 계산이나 기준값에 넣지 않습니다. 측정 구간은 계속 27~87%의 고정된 31개 단면입니다. 화면의 폭 감소와 그래프는 시간상수 약 0.12초로 완화한 값이며, CSV에는 원시 변화율과 필터 값을 따로 저장합니다.

가림/화면 밖 구간은 빈칸으로 남깁니다. 윤곽 탐색 경로가 손 영역을 통과해도 그 부분을 측정값으로 채우지 않습니다. 뚜껑/바닥을 놓치면 축 좌표와 변형값도 빈칸입니다. 기준에서 관찰하지 못한 단면을 나중에 정답처럼 추가하지 않습니다.

### 손을 병 몸체로 인식하는 현상 보정

관절 점 주변의 손 영역에 더해, 그 손에서 관찰한 색 분포와 인접 픽셀의 연결성을 이용해 손가락 바깥 살·손바닥 가장자리를 제외합니다. 고정된 피부 RGB 범위는 사용하지 않습니다. 색이 불분명하면 관절 기반 제외 영역을 사용하며, 조명·피부색·배경에 따라 오차가 남을 수 있습니다.

예상 병 경계가 손에 가려졌으면 탐색 경로가 손 바깥의 더 강한 선으로 옮겨가도 측정하지 않습니다. 기준 윤곽과 현재 윤곽도 손 영역 위에 그리지 않습니다. 병 축을 확보한 뒤에는 손이 포함될 수 있는 일반 검출 상자를 몸체 윤곽처럼 표시하지 않습니다. 반대편이 가려졌다는 이유로 보이는 쪽 윤곽까지 지우지 않습니다.

손을 추적하다 잠시 놓치면 몸체 측정을 멈추고, 다시 찾으면 기존 기준값으로 이어갑니다. 손 관절 분석과 병 추론은 계속 별도로 실행합니다. 가려진 부분을 채우지 않으므로 이전보다 표시되는 몸통 선이 줄어들 수 있습니다. 31개 중 비교 가능한 단면이 6개 미만이면 폭·변형 통계와 기준값을 만들지 않습니다.

손을 처음 검출하기 전에 만든 윤곽이 이미 화면에 있던 손을 포함했을 가능성도 검사합니다. 처음 손을 찾았을 때 병 좌표로 맞춘 초기 영상과 현재 손 영역이 거의 같으면, 손을 제외하지 못한 기준으로 판단해 몸통 기준과 진행 중인 폭 보정을 다시 수집합니다. 처음에는 손이 없다가 나중에 들어온 경우처럼 영상이 충분히 달라지면 기존 기준을 유지합니다. 이 검사는 영상 밝기 비교에 따른 보수적인 규칙이며, 실제 손 영역 정답을 판별하는 학습 모델은 아닙니다.

투명한 몸통 너머의 배경 특징점이 바닥을 붙잡는 오류를 줄이도록 뚜껑과 관찰한 바닥 테두리 근처에서 특징점을 고릅니다. 두 끝점의 움직임이 뚜껑에서 독립적으로 관찰한 움직임과 충돌하면 해당 프레임을 측정하지 않고 재탐색합니다. 자동 후보 확정은 화면상의 정지 여부뿐 아니라 이전 영상과의 실제 대응도 확인합니다. 손을 찾은 상태에서는 손에서 먼 배경 병을 선택하지 않습니다.

## CSV와 JSON

`recordings/outline_날짜_시간.csv`와 같은 이름의 JSON을 저장합니다. JSON에는 초기 두 점, 정렬 좌표계, 단면 위치, 초기/기준 좌우 윤곽과 손 각도가 있습니다. 기존 파일을 덮어쓰지 않습니다. schema_version은 2입니다.

| CSV 열 | 의미 |
| --- | --- |
| source_frame_id | 실시간 자동 모드에서 실제 분석한 카메라 프레임 번호. 건너뛴 번호는 미분석 프레임 |
| capture_time_s | 실시간 자동 모드 세션 시작 후 촬영 시각(초) |
| analysis_latency_ms | 촬영부터 CSV 작성 직전까지 걸린 시간. 큐 대기와 추론 포함 |
| bottle_model | 사용 모델: yolo11n_seg / yolox_416_detection_only / experimental_shape |
| cap_x_px, cap_y_px, base_x_px, base_y_px | 현재 영상의 두 중심, 소수점 좌표 |
| axis_length_px, axis_tilt_deg, axis_scale_ratio | 축 길이, 화면 수직 대비 기울기, 현재/초기 축 길이 |
| axis_quality | 특징점과 패치 일치 기반 진단값. 신뢰확률/실측 정확도가 아님 |
| profile_left_canonical_px, profile_right_canonical_px | 정렬 영상의 단면별 좌우 x 배열. 가린 곳은 JSON null |
| profile_coverage | 기준과 현재를 비교할 수 있는 단면 비율(0~1). 기준 전에는 초기 관찰 비율 |
| hand_occluded_profiles | 손 제외 마스크가 예상 좌우 경계에 닿아 제외한 단면 수. 실제 가림의 정답 수가 아닌 진단값 |
| left_edge_coverage, right_edge_coverage | 측정 높이 31개에서 각 측면을 독립적으로 관찰한 비율. 상대편이 보인다는 뜻은 아님 |
| median_width_reduction_pct | 유효 단면별 (기준 폭-현재 폭)/기준 폭×100의 중앙값, 원시값 |
| filtered_width_reduction_pct | 위 중앙값의 시간 필터 결과. 추적 소실 시 초기화 |

| center_shift_rms_pct | 단면 중심 변위의 RMS, 기준 폭 대비 %. 휨/비대칭 지표 |
| visible_area_reduction_pct | 인접한 유효 단면 사이의 영상 2D 면적 감소율. 같은 가시 구간끼리 비교 |
| area_coverage | 면적을 계산할 수 있는 인접 단면 쌍의 비율. 60% 미만이면 면적값은 빈칸 |
| baseline_noise_pct | 단면별 1.4826×MAD/기준 폭×100의 중앙값 |

정렬 영상의 뚜껑은 (160,32), 축 길이는 320입니다. JSON의 profile_positions에 높이 비율이 있고, axis_seed_is_model_estimate는 학습 모델의 영역에서 축을 추정했는지 나타냅니다. 31개 중 최소 6개 단면이 있어야 폭 변형 통계를 계산합니다. 기준값은 단면마다 최소 3개이면서 유효 기준 샘플의 60% 이상에서 관찰되어야 합니다.

일부 단면만 보이면 통계는 **그 보이는 구간의 변화**입니다. 실제 찌그러진 곳을 손이 모두 가리면, 다른 곳이 멀쩡하다는 이유로 전체 변형이 없다고 결론 내릴 수 없습니다. Partial contour와 coverage를 확인하세요. 가려진 부분의 부피나 힘을 복원하지 않습니다.

## 촬영 조건과 한계

투명한 병의 양옆 경계가 실제 화면에 보여야 합니다. 무늬 없는 무광 배경과 부드러운 측면 조명부터 시험하고 강한 정면 반사광을 줄이세요. 뚜껑과 바닥을 가리지 않고 화면 안에 유지합니다. 특징이 부족하면 조명/촬영 방향을 바꾸고 A로 다시 탐색합니다.

카메라 쪽으로 기울이는 **3차원 원근 변화**, 병 자체의 높이 변화, 축 주위 회전은 두 점만으로 분리할 수 없습니다. 축 길이에는 거리 변화와 실제 병 변형이 섞일 수 있으므로 axis_scale_ratio도 확인하세요. 카메라와 촬영 방향을 유지합니다.

면적은 영상상 가시 면적이며, 실제 부피·압력·악력(kgf)이 아닙니다. 손 모델이 손을 놓치면 가림 제외도 불완전해집니다. 검지~새끼손가락 MCP 각도는 손목을 손바닥 쪽 기준점으로 쓰는 근사값입니다. 실제 사용자 영상에 대한 정확도 수치는 아직 없습니다.

## 참가자와 악력계 기준값

```powershell
.\.venv\Scripts\python.exe main.py --participant P01 --trial-id T01 --bottle-id PET500-empty-capclosed --tested-hand right --grip-kgf 31.5 --label-source dynamometer
```

`31.5`는 예시이며 해당 참가자·해당 손에서 실제 측정한 값으로 바꿉니다. 다른 참가자가 정답값을 생략하면 임시 80kgf를 붙이지 않으며, 개인 보정값이나 학습 모델이 없으면 feature만 저장합니다. 왼손은 `--tested-hand left`로 지정합니다. 같은 참가자라도 병 조건·손별 보정값은 분리됩니다. 입력한 손과 실제 촬영한 손의 일치 여부를 자동으로 검증하지는 않습니다.

정답값은 기록과 보정·학습에 사용하고, 예측 feature로 사용하지 않습니다. 기준 보정 뒤 현재 촬영의 정답값 없이 실행하려면 같은 참가자·손·병 옵션에 `--predict-only`를 붙입니다. 최대 악력은 시행별 라벨이며 영상 모든 프레임의 실제 힘이 아닙니다.

53개 영상 신호에서 224개 시행 요약 feature를 계산합니다. 관절 각도·변화, 손 크기로 정규화한 모양, 관찰한 병 변형, 손 기반 추정 윤곽, 변화 속도·유지 시간 등을 포함합니다. 다음 명령으로 상관관계와 모델 비교 보고서를 만듭니다.

```powershell
.\.venv\Scripts\python.exe grip_analysis.py analyze --recordings recordings
```

`analysis/grip_report.html`을 브라우저로 확인합니다. 동일인의 반복 촬영은 참가자별로 요약하며, 상관관계와 모델 선택은 참가자를 분리해 평가합니다. 임시 정답값은 기본 학습 대상에서 제외합니다. 데이터가 부족하거나 단순 평균보다 검증 성능이 나쁘면 모델을 저장하지 않습니다. 인식 품질 통과는 악력 정확도 검증을 의미하지 않습니다.

병 종류·내용물·뚜껑·쥐는 위치·손 크기·사용 손·촬영 방향과 영구 변형된 병의 교체 기준을 기록하세요. [참고 일본 연구](https://lclab.org/projects/plasticbottle)는 손가락 각도와 내부 공기압의 관계를 조사한 기초 연구이며 이 프로그램의 kgf 정확도를 입증하지는 않습니다.

## 이전 모드와 모델

- `--shape-only`: 이전 뚜껑·몸통·바닥 규칙 기반 자동 탐색. 모델이 필요 없는 실험용 경로이며 기본 인식 방법은 아닙니다.
